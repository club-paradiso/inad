# Known limitations and next priorities

This is a playable international **procedural foundation**, not a production immigration decision product.

1. Overseas outcomes are authored SIMULATION_RULE feedback. No foreign visa eligibility, legal refusal, detention, removal, asylum or appeal engine exists. Case-specific effective-date and exception validation remains necessary. NZ Act retrieval was denied (403); statutory verification remains pending.
2. Nine fixtures, two canonical questions each, two documents and three checks per case. No overseas AI/free-text interview, government connection, real traveler database, authentic security check or real staffing data. Search is scoped to the current synthetic case. Foreign career scoring/campaign progression is not implemented.
3. KR case/input/document continuity across country switches is in-tab. Refresh uses existing KR checkpoints; it does not persist a mid-interview Korean draft. Foreign drafts persist independently.
4. Invalid/future saves are protected and block imports into those slots. Users can export raw stored records and a separate current-input copy. Import rollback is best effort if browser storage remains permanently unavailable. Concurrent editing in multiple tabs is not merged.
5. Accessibility checks cover semantic controls, keyboard actions/focus, dialogs, task navigation, target sizes, selected-control contrast, large text/high contrast preferences and overflow. This is not full WCAG 2.2 AA certification. Screen-reader, Safari/iOS and Firefox testing remains outstanding; automated browser runs use Chromium on macOS.
6. Editable Figma desktop references exist. Tablet/mobile Figma variants and pre-existing global Figma token drift reconciliation remain. The runtime retains the existing token file and exact layouts are captured in screenshots.
7. System-font rendering depends on platform. Official source URLs may move; dates in the register describe the retrieved versions, not automatic updates.

Next work: independent legal review and precise version/effective-date manifest; additional country-specific procedural scenarios with richer evidence relationships; cross-browser and assistive-technology QA; multi-tab conflict handling; global design-library reconciliation. Do not enable legal dispositions merely because a source page was retrieved.
