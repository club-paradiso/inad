# INAD: 제12조 v6.1 Release Notes

## Release hardening

v6.1은 v6.0 RC의 기능을 유지하면서 저장 데이터 관리, 법령 기준 버전 표시, 내장 진단과 오류 복구 수단을 추가한 안정화 릴리스입니다.

### 새 기능

- **시스템·데이터 관리 센터**
  - 게임 버전, 법령 기준일, 저장 스키마, 현재 세션 상태 표시
  - 출입국관리법·난민법·난민법 시행령·형사소송법 기준 버전 표시
  - 2026-10-02 형사소송법 일부 시행예정 개정 경고
- **저장 데이터 내보내기/불러오기**
  - INAD_SAVE_BUNDLE v1 JSON 형식
  - 체크섬 검증으로 손상 파일 거부
  - 허용된 INAD 저장 키만 복원
  - 근무기록, 프로필, 캠페인, 체크포인트, 접근성 설정 포함
- **선택적 초기화**
  - 현재 체크포인트만 삭제
  - 근무기록·경력·캠페인 삭제
  - 모든 INAD 로컬 데이터 삭제
- **내장 시스템 진단**
  - 105명 여행객 데이터와 고유 ID
  - 12개 핵심 사건
  - 36명 근무 큐 참조
  - 초상화 내장 에셋
  - DOM 중복 ID
  - 외부 네트워크 에셋
  - 브라우저 저장소
  - 근무기록/체크포인트 JSON
  - 필수절차 데이터 참조
  - 뷰포트 오버플로
  - 런타임 오류 수집
  - 법령 기준일과 저장 스키마
- **진단 보고서 내보내기**
  - 텍스트 파일로 현재 무결성 상태 저장
