# 02 — Competitive originality audit

조사일 2026-10-19. **EXTERNALLY VERIFIED**는 개발자/퍼블리셔가 공개한 동작 설명을 확인했다는 뜻이다. 이번에 경쟁작 10개를 설치해 완주한 것이 아니다. 상점 문구가 즐거움·난도·판매 실적을 입증하지 않는다. 아래 비교/등급은 **INFERRED**이며 수치형 ‘표절률’은 사용하지 않는다.

## Papers, Please: 무엇이 실제로 겹치는가

Papers, Please의 확인된 중심은 국경 담당자가 도착자의 문서를 조사하고 입국·거부·구금을 결정하는 반복이다.[S1,S2] 개발자 모바일 회고는 문서 작업 영역, 상호 대조, 화면 공간과 조작의 관계를 직접 설명한다.[S3] 규칙 증가·급여와 가족 유지비·벌금·정치적 개입·20개 엔딩·무한 모드는 보조 출처 S4에서 교차 확인했다. 숫자나 최신 포팅 정보를 비교의 근거로 과장하지 않는다.

| 요소 | Papers, Please의 구조 | INAD의 확인된 구조 | 판정 |
|---|---|---|---|
| fantasy | 통과 권한을 가진 국경의 말단 | 입국 심사관으로 권한 행사 | 중심 동일 |
| 1회 loop | 도착→서류확인→질문/조사→통과/거부→다음 | 도착→문서/질문/조회→처분→채점→다음 | 중심 매우 가까움 |
| 문서 | 작은 작업 공간에서 항목 대조 | 탭/문서 필드와 조회 기록 | 조작·표현 차이, 인지 과제 유사 |
| 규칙 변화 | 진행하며 요구 문서·조건 증가 | 고정 사건의 required와 특수 절차 | 동일하지 않으나 적합성 판단 공통 |
| 시간 | 근무 시간 내 처리량이 생활과 연결 | 행동별 simSeconds·부하·피로·효율 | 실제 압박 방식은 다름; 처리량 동기 공통 |
| 돈·생존 | 실수·급여·가족 유지의 압력 | 등급·업무 수치·캠페인 이월 | INAD가 같은 생계 갈등을 구현한 것은 아님 |
| agency | 규칙 준수와 사람/정치 선택 간 충돌 | 질문/조사 순서, 사유·특수절차 선택 | 선택의 장기 의미는 기존작보다 확인 근거 약함 |
| 서사 | 반복 업무 속 scripted 인물/정치 사건 | 정해진 core와 generated normal, campaign anchor | 랜덤+작성형 혼합은 관습 |
| 도덕 | 개인적 비용이 규칙 위반과 충돌 | 절차적 정답과 효율을 주로 채점 | 사실성이 감정적 비용을 자동 생성하지 않음 |
| 인물 | 짧은 만남의 축적과 재등장 | personas, 표정, 작성형 응답 | 표현량 증가, 결과 지속성은 제한적 |
| 감정 결과 | 선택이 생계·관계·정치 결말과 연결 | 사건 보고와 운영 이월 | INAD의 실제 감정 몰입은 미측정 |
| 진행 | 규칙·이야기·끝의 변화 | full/quick/daily/campaign·업적 | 모드 수≠새 추론 |
| 재플레이 | 다른 선택/엔딩·무한 반복 | seed 변형·날짜별 core 선택 | 순서 변형과 지식 초기화는 별개 |
| 시각 | 고유한 픽셀/문서 작업대 | 현대 업무 콘솔과 초상·절차 화면 | 구체적 표현 차이는 있으나 전체 자산 권리 미감사 |
| mechanic↔story | 처리 속도와 인간 선택에 같은 비용 | 행위 체크와 정답이 서사를 종결 | INAD에 필요한 것은 더 많은 설정보다 결과 구조 |
| Lock | 문서/진술의 불일치를 드러내는 비교와 인접 | ID쌍 match가 authored clue 공개 | 명칭 변경만으로 독창적이지 않음 |

**반사실 검정:** 국명·인물·법률명·그래픽을 제거해도 INAD의 주된 행동은 ‘서류와 진술을 확인해 사람을 들일지 결정’이다. 지금의 차이는 더 세분된 절차와 인터뷰 입력 방식에 집중한다. 이는 해당 주제의 시뮬레이션으로는 가치가 있을 수 있지만, 새로운 게임의 차별화 증거는 약하다.

유사성을 과장하지 않을 차이도 있다. INAD의 시간은 `spendWork`로 부과하는 작업시간이며 같은 실시간 생계 경제를 복제하지 않는다. 법적 절차 분리·통역·근거 설명은 다른 목적을 가진다. 그러나 그 목적에 돈/시간을 쓸 실제 audience는 UNKNOWN이다.

## 더 넓은 경쟁 지형

아래 ‘시그니처’는 그 작품을 설명하는 특징이지 해당 작품이 발명했다는 특허적 주장 아님. 경쟁 강도는 INAD 현재 loop 기준이다.

| 게임 / 근거 | 검증된 주요·보조 행동 / 결정 | 정보·압력·피드백·진행 | 차별화 학습 / 경쟁 관계 |
|---|---|---|---|
| Papers, Please [S1–4] | 문서대조·질문/검사, 입국/거부/구금 | 규칙과 방문자; 시간/생계; 벌칙·서사 결과 | 반복 업무가 인간적 비용과 결합. 직접 비교 대상 |
| Not Tonight [S5] | 문지기로 ID/초대명단 확인, 입장관리 | 장소별 일·장비/경제·저항 이야기 | 직업 변경만으로도 여전히 처리 loop. 직접 인접 |
| Contraband Police [S6] | 서류검사+UV/차량 수색·물리적 밀수품 회수 | 사격/추격·초소 예산/개선·서사 개입 | 공간 탐색과 행동이 문서 밖의 숙련을 만듦. 직접 인접이나 제작 규모 다름 |

| Beholder [S10] | 관리인으로 감시·수색·신고/묵인/협박 | 주민과 가족 이해관계, 분기 결말 | 권력·개인 위험의 선택. B의 비교 대상 |

| Ace Attorney: Apollo Justice Trilogy [S12] | 현장 조사·증거 수집→증언 반박/교차신문 | 작성된 주장·모순, 법정 진행 | 단순 증거쌍 대조는 이미 익숙한 문법. 시리즈 전체를 동일하게 일반화하지 않음 |

## 동작 단위 비교 행렬

등급 기준: **가까움**=역할·대부분의 반복 동사·종결 결정까지 겹침; **인접**=일부 정보 처리 동사는 겹치나 주요 목표/결과가 다름; **약함**=설정 또는 추론 관습만 공유. 저작권 보호 범위 판단이 아니다.

| 축 | INAD 현재 | Papers, Please | The Operator | 제안 E |
|---|---|---|---|---|
| 1차 행동 | 질문·문서/조회 확인 | 문서검사 | DB/미디어 분석 | 주장에 쓰인 출처 계보 추적 |
| 2차 행동 | 대조·절차 화면 | 질문/추가 검사 | 현장 요청에 도구 사용 | 전제 철회·독립 근거 재확보 |
| 주요 결정 | 허가/불허/특수절차 | 입국/거부/구금 | 요청의 문제 해결 | 초안 근거 수정/유지/미해결 인계 |
| 정보 획득 | unlock 질문·lookup | 제출서류·질문/검사 | 파일·DB·영상 | 진술·원장·전송기록의 출처 검증 |
| 증거 조작 | ID쌍 비교→clue | 항목대조 | 도구로 자료 해석 | 판단에 채택/철회; 원자료 불변 |
| 인물 상호작용 | 작성형 대사+선택형 분류 | 짧은 대화/방문 | 현장 요원과 통신 | 확인 질문과 오류 설명의 응답권 |
| 불확실성 | 숨은 정답/누락 행동 | 문서 진위·요구조건·의도 | 단서 의미 | 중복 출처·시점 차이·판단 범위 |
| 실패 | 잘못된 처분/절차·수치 | 오판·시간/생활 비용 | 해결 실패/진행 장애(세부 미검증) | 무근거 단정·오류 미수정·권한 초과 |
| 피드백 | 점수/단서/디브리프 | citation/경제/서사 | 도구 결과·진행 | 영향받은 주장과 남은 불확실성 |
| 서사 진행 | core+생성 큐, 제한된 arc | 일별 반복과 작성형 사건 | 연결된 수사 이야기 | 판단 수정이 다음 기록을 바꿈 |
| 자원 압력 | simSeconds·피로·queue | 실시간·돈 | 이번 자료로 정량 미확인 | 행동 슬롯3, 독해시간 무제한 |
| 재플레이 | seed/날짜/등급 | 다른 선택/결말·무한 | 정해진 수수께끼 재해석 | 다른 provenance 구조; 동일 정답 반복 제한 |
| signature 주장 | Statement Lock | 서류심사와 생계·도덕 비용 | 분석 도구로 현장 지원 | 근거 철회 시 하위 주장의 지지 상실 |
| 현재 INAD와 유사 | — | **가까움** | **인접** | 역할·끝·자원 동기가 달라질 가설 |

The Operator의 실패조건/정량 자원 모델은 상점만으로 확정하지 않았다. E는 아직 실제 mechanics가 아니라 구현할 계약이다. E의 가장 가까운 비교는 ‘정보를 선택해 제도에 넘기는’ Orwell과 ‘근거를 해석하는’ 여러 추리게임이지 PP만이 아니다.

## 기존 차별화 주장의 반사실 검정

| 주장 | 분류 | 결정·실패·즐거움을 바꾸는가 / 작은 확장으로 옮길 수 있는가 |
|---|---|---|
| 한국 실제 법·공항 | 사실성/표현 차이 | 요구 규칙을 바꾸지만 기본 목적은 동일. 문서/규칙 확장으로 옮길 가능성 높음 |
| 자연어·음성 면담 | 점진적 개선 | 작성형 질문으로 매핑되는 한 입력 비용 변화. 열린 문제 해결과 다름 |
| 생동하는 초상·표정 | 표현 차이 | 감정 해석 강화 가능; 정답 단서처럼 보이면 해로움. 이식 쉬움 |
| 통역과 절차 구분 | 의미 있는 기계적 확장 가능 | 적절한 의사소통과 절차 순서가 실질 결과를 바꾸면 가치. 지금은 토큰 충족과 섞임 |
| Statement Lock | 현 구현은 점진적 확장 | 증거쌍→clue는 관습. F1–4와 선택적 완료 경로로 defining mechanic 미달 |
| 설명형 근거·source registry | 점진적 개선 | 이해/신뢰 개선. 플레이어가 근거를 구성하지 않으면 설명 도구에 머묾 |
| 캠페인 연결 | 잠재적 defining mechanic | 실제 원인망·이전 선택이 다음 사건을 바꿔야 함. 현재 actions progression만으로 부족 |
| daily/quick/seed | 장르 관습 | 세션 길이와 재방문 편의. 독창적 핵심 동사 아님 |
| 실시간 공항 부하 | 점진적 개선 | 압력 수치 변화. 새 선택 없이 외부 의존성만 늘 수 있음 |
| E의 근거 철회 | 잠재적 defining mechanic | 판단 범위/인계/실패가 바뀜. PP의 소규모 모드로도 흉내낼 수 있으나 중심 역할과 완료 체계까지 바꿔야 함 |

‘어떤 게임도 모드로 만들 수 있다’는 논점을 독창성의 면제부로 쓰지 않는다. E가 단지 빛나는 노드를 클릭하는 퍼즐이면 Ace Attorney식 대조/기존 Lock으로 다시 수렴하며 권고를 철회해야 한다.
