# INAD v12 — 현장 관점 검토와 개편 기록

작성 2026-11-11 · 기준 `main` @ `e968d5b` · 대상: 한국 모드(인천 T2) 사건 12건, 생성 승객, 작업대 UX, 게임 흐름.

근거의 한계부터 적는다. 이 문서의 판단은 공개 법령 원문(출입국관리법 제7조·제11조·제12조·제12조의2·제48조, 국가법령정보센터 2026-10-02 시행본을 2026-11-11에 조회)과 빌드한 게임을 직접 플레이한 기록에서 나왔다. 법무부 내부 심사기준·전산 화면·비공개 지침은 근거로 쓰지 않았고, 이 저장소의 원칙대로 재현하지도 않는다.

## 1. 진단: 왜 심심했는가

### P0-1. 판단 패널이 정답지였다

수정 전 `ICN-S2-005`(쩐 반 민)를 열면, 질문을 하나도 하지 않은 상태에서 우측 판단 패널이 이렇게 읽혔다.

| 항목 | 질문 0개·조회 0개 시점의 표시 |
|---|---|
| 입국목적 | 미해결 · 관광 일정 구체성 부족 |
| 여행계획 | 부족 · 귀국편 없음 |
| 체재능력 | 취약 · 30일 대비 체재비 부족 |
| 국내관계 | 미해결 · 연락처 관계 불명 |
| 법적 근거 목록 | "송환·출국대기" 노드가 불허로 끝나는 사건에만 존재 |
| 단서 | 핵심 0/6 · 전체 0/9 |

원인은 `renderMatrix()`가 사건 데이터의 `evidence`(디브리프·판정용 최종 평가)를 그대로 그렸기 때문이다. 같은 문제가 여러 곳에 있었다.

- `ICN-S3-012`는 출입국기록을 조회하기 전부터 "입국자격: 입국금지 · 강제퇴거 후 5년 미경과"가 떠 있었다.
- 생성 승객 중 유상활동 변형은 처음부터 "입국목적: 불일치 · 국내 유상활동 계획과 양립하지 않음"이었다. 36명 중 누가 문제인지 패널만 훑으면 알 수 있었다.
- 단서 보드는 저작 사건에만 나타났다. 보드가 보이면 "뭔가 있는 사람"이었다.
- `ICN-S3-010`의 신고 목적 칸은 난민신청 의사를 밝히기 전부터 "관광 → 난민신청"이었다.
- 질문 탭의 "국내관계 0/3 · 3 남음"은 아직 열리지 않은 후속 질문까지 세었다. 숨은 질문이 몇 개인지, 언제 더 캘 것이 없는지 알려 줬다.
- 재심 화면의 "재심 인계 사유"는 심사관이 본 적 없는 평가 항목을 나열했다.
- 첫 근무 코치는 단서 종류와 무관하게 "불일치 또는 결격 사유가 확인되었습니다"라고 말했다. 정상 입국자의 확인 단서에도 같은 문장이 나왔다.

결과적으로 플레이는 "패널이 알려 준 결론을 향해 목록의 버튼을 전부 누르는 일"이었다. 추론할 것이 없었다. 창구에서 실제로 손에 쥐는 것은 판독 결과와 눈앞의 사람과 그 사람의 말이고, 나머지는 물어서 얻는다. 게임도 그래야 한다.

### P0-2. 여권 성별과 초상이 뒤바뀐 승객 53명

일반 승객 풀(TRV-0014 이후)에서 여권 성별과 초상의 외형이 어긋난 승객이 53명이었다. 예: `TRV-0090` 누스라트 자한(여권 F)에 수염 난 남성 초상, `TRV-0072` 페트르 드보르자크(여권 M)에 여성 초상. 같은 국적의 인접한 두 승객끼리 초상 파일이 서로 바뀐 형태가 대부분이라, 생성 순서가 한 칸 밀린 것으로 추정한다(추정이며 생성 스크립트 기록으로 확인하지는 못했다).

신원 대조가 핵심인 게임에서 이건 장식 문제가 아니다. 플레이어는 "여권과 사람이 다르다"고 읽는데 화면은 "생체 일치 98.9%"라고 한다. 진짜 위조 사건(`ICN-S3-009`)의 신호가 잡음에 묻힌다.

### P1-1. 수치인 척하는 연출값

대상자 패널의 "긴장 38 · 협조 70" 막대는 판정 근거가 아니라고 옆에 써 붙여야 할 만큼 판정처럼 보였다. 근거가 아닌 값에 숫자와 막대를 주고 면책 문구를 다는 것은 CLAUDE.md의 금지 항목("판정 근거가 아닌 값을 판정처럼 보이게 하는 시각") 그대로다.

### P1-2. 시작 화면에 주 행동이 둘

어두운 히어로(라이브 인터뷰)와 같은 크기의 파란 "근무 시작"(36명, 약 1시간)이 나란히 있었다. 처음 온 사람이 36명 근무를 누르면 브리핑 모달과 6단계 화면 안내를 거친 뒤 1시간짜리 근무에 들어간다. 각 모드가 몇 명이고 얼마나 걸리는지는 어디에도 없었다.

## 3. 사건 12건 검토

판정 데이터는 동결 대상이라 이번에 손대지 않았다. 아래는 승인을 받아야 진행할 수 있는 지적과 제안이다.

### 잘 된 것

- 006(타인 명의 숙소 → 소명되어 허가)과 007(숙소 설명 실패 → 취업 진술 → 불허)이 같은 출발점에서 갈린다. "수상해 보임"과 "요건 미충족"을 구분하게 만드는 좋은 쌍이다.
- 008(장비 소지 상용 방문 → 허가), 012(무사증 국적이지만 개인 입국금지)는 국적과 입국 근거를 분리한다는 원칙을 사건으로 보여 준다.
- 009·010·011은 절차를 섞지 않는다(위조 발견 ≠ 자동 체포, 불회부 ≠ 입국불허, 다른 요건이 정상이어도 생체정보 의무는 별개).

### 법령 기준일 관련 관찰

`RELEASE.laws`는 출입국관리법을 "2026.01.23 시행 · 현행"으로 적고 있다. 2026-11-11 조회 시 국가법령정보센터의 현행본은 공포 2026-08-04, 시행 2026-10-02다. 제11조, 제12조, 제12조의2는 이 게임이 인용하는 항·호 번호와 문언이 현행본에서도 같다는 것까지 확인했다. 제7조와 제48조제6항도 같다. 제7조의3, 제13조, 제47조, 제76조, 시행령·시행규칙은 대조하지 않았다. `docs/legal-review.md` 6번으로 기록했다.

## 4. 다음 단계 제안 (미구현, 승인 필요)

우선순위 순.

1. **1차 심사와 재심의 역할 분리.** 지금은 한 사람이 창구에서 심층 조사까지 한다. 1차의 일은 "허가 / 재심 인계"를 짧은 시간 안에 가르는 것이고, 깊이 파는 일은 재심의 것이다. 정규 근무를 "1차 창구 30명(1인당 60–90초, 인계 사유를 직접 적음) + 재심실 3–4건(지금의 깊은 조사)"로 나누면 생성 승객은 채움재가 아니라 리듬이 되고, 저작 사건은 재심실에서 제대로 쓰인다. 인계 사유를 플레이어가 고르게 하면 "왜 넘겼는가"가 채점 대상이 된다.
2. **사건 유형 보강.** 공개 법령만으로 저작 가능한 유형: 환승 승객의 연결편 부재, 사전여행허가 미보유 무사증 국민, 출국명령과 강제퇴거의 차이(012의 변주), 등록외국인의 체류기간 만료 임박 재입국, 17세 미만 생체정보 면제(011의 반대 사례), 조건부 입국허가(제13조, `progress.md`에 조사 완료로 남아 있음).
3. **C-1–C-3 첫 진술·조회 문구 수정.** 판정은 그대로 두고 정보가 나오는 순서만 바꾼다. `personas.js`의 대사 검사(`dialogue-guard`)와 함께 고쳐야 한다.
4. **Figma 동기화.** 이번 변경은 코드가 먼저다. `docs/design-workflow.md`에 따라 시작 화면 사다리, 미확인 행, 현장 노트를 `[Implemented]` 섹션에 반영해야 한다. 이번 작업에서는 Figma 파일을 수정하지 않았다.
